线性定常系统的状态空间建模与响应

编辑系统矩阵（行用 ; 分隔、列用逗号分隔），观察 ẋ=Ax+Bu、y=Cx 在单位阶跃输入下的状态与输出演化。默认系统对应传递函数 9/(s²+1.2s+9)。

判读：状态 x₁（位置类）与 x₂（速度类）的物理含义由 C 决定；A 的特征值决定模态——负实部收敛、正实部发散、共轭对对应振荡。

能控性与能观性判别

构造能控性矩阵 Wc=[B AB ⋯ An−1B] 与能观性矩阵 Wo=[C; CA; ⋯]，用高斯消元求秩：秩等于 n 即完全能控/能观。

物理直觉：能控 = 存在输入能把任意初态拉回原点；能观 = 由输出 y(t) 能反推全部状态。上图以当前系统画 x₁-x₂ 相平面轨迹（阶跃输入，起点 (1,1)）。

状态反馈极点配置（Ackermann 公式）

对完全能控的被控对象设计状态反馈 u=−Kx，把闭环极点放到期望位置。拖动滑块设定期望阻尼比 ζ 与自然频率 ωn，右侧实时对比开环与闭环阶跃响应。

校验锚点：对默认双积分器，理论结果 K=[ωn², 2ζωn]——拖滑块看 K 是否与手算一致。注意闭环响应与开环（发散）的天壤之别。

全维状态观测器：用输出重构状态

真实状态不可全测时，构造观测器 ẋ̂=Ax̂+Bu+L(y−Cx̂)。拖动滑块设定观测器极点带宽 α（极点放在 −α±jα，应快于被控对象极点），看估计 x̂ 追上真值 x 的过程。

初始估计误差 x(0)−x̂(0)=(1,1)ᵀ。误差动态由 A−LC 决定——α 越大收敛越快，但对测量噪声越敏感（这是观测器设计的核心权衡）。

卡尔曼滤波：从噪声测量中估计状态

一维匀速运动跟踪：真值 p(t)=v·t（带过程噪声的加速度扰动），只能测到含噪位置。KF 用「预测+校正」在线估计 [位置, 速度]。拖动噪声滑块，看估计精度如何碾压单次测量。

数据固定随机种子（可复现）。结论指标：估计 RMSE 应显著小于测量 RMSE；σa 调大时滤波器更「信任」测量（Kalman 增益上升）。
